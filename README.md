This is the repo for labs for GES 778. To get started, fork this repo into your
GitHub account following [these
instructions](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo)
(we'll go through this together). You'll set up your copy of the repo to pull
updates from the main one in the umbc-viz organization, so as I add each week's
labs, you'll be able to copy them over (theoretically :crossed_fingers:).

Each lab has its own directory, numbered to keep them in order. There are empty
utility scripts in the `utils` folder; you'll add helper functions, color
palettes, and other bits of code to those as you go. Feel free to add other
scripts there as you like.
